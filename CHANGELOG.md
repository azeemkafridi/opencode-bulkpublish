# Changelog

## 0.1.0 — 2026-10-28

- First release: connect an API key, list channels, compose with per-network
  character counts, attach an image or video, publish now, schedule or save a
  draft, see recent posts with their status, and retry failed ones.
- `/bulkpublish` slash command, palette commands, a side panel tab and a
  settings page.
- Your API key is only ever sent to the address it was connected on.
